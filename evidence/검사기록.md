## 4. 등록을 중간에 취소하면 서버에 아무것도 저장되지 않는다

**질문은 발급되었지만**

```json
{
  "flowId": "a02fd023-9cef-43b8-9898-55a54401403d",
  "challenge": "gibBFPvrLjE6Z2UM5tf6i99VsH2or8SO6gUKE-uDDPU"
}
```

여기서 사용자가 기기 화면에서 취소하면 `/api/register/verify`가 호출되지 않습니다. 저장은 verify에서만 일어나므로 서버에는 아무것도 남지 않고, 보관 중이던 질문은 120초 뒤 만료됩니다.

> ✅ 통과 — 취소한 뒤에도 저장된 패스키 수가 늘지 않음 (T08-C25) (비로그인 상태라 목록 조회 자체가 401 — 저장은 verify 단계에서만 일어남)

## 6. 로그인 — 서명이 맞을 때만 통과한다

**실패한 요청 — 서명을 한 바이트 망가뜨림**

```json
{
  "request": "POST /api/login/verify (flowId=e86a5659-1cfd-482d-b9d8-acaed4be4807, signature 변조)",
  "status": 401,
  "body": {
    "error": "verification_failed"
  }
}
```

> ✅ 통과 — 틀린 서명은 거절된다 (T08-C29 / C30)

**실패한 요청 — 등록된 공개키와 짝이 아닌 개인키로 서명**

```json
{
  "status": 401,
  "body": {
    "error": "verification_failed"
  }
}
```

> ✅ 통과 — 짝이 맞지 않는 열쇠로는 통과하지 못한다

**실패한 요청 — 서버에 등록된 적 없는 패스키**

```json
{
  "status": 401,
  "body": {
    "error": "unknown_credential",
    "message": "서버에 등록되지 않은 패스키입니다."
  }
}
```

> ✅ 통과 — 등록되지 않은 패스키는 거절된다

**성공한 요청**

```json
{
  "request": "POST /api/login/verify (flowId=dfc1c2ee-6606-422e-993a-13c9ad1b689f)",
  "challenge": "XMm73GLQkgHEzUjJmZiRa1P5kpk3xFNAa9JH-4a0YGo",
  "status": 200,
  "body": {
    "verified": true,
    "userId": "jang",
    "displayName": "장성혁 (본인 계정)",
    "usedCredentialLabel": "노트북 크롬",
    "session": "y5FY••••••••(마스킹됨)"
  }
}
```

> ✅ 통과 — 맞는 서명은 통과한다 (T08-C29)

로그인 뒤 사람을 알아보는 수단은 **서버에 보관된 세션**이며, httpOnly 쿠키(`sid`)로 오갑니다. 토큰을 화면에 두지 않습니다. (T08-C32)

## 11. 패스키가 하나도 남지 않으면 어떻게 되는가

**마지막 하나를 그냥 지우려 하면**

```json
{
  "status": 409,
  "body": {
    "error": "last_passkey",
    "message": "마지막 남은 패스키입니다. 지우면 이 계정으로 다시 들어올 수 없습니다. 그래도 지우려면 confirmLast=yes를 붙여 주세요."
  }
}
```

> ✅ 통과 — 마지막 패스키 삭제는 한 번 더 확인을 요구한다 (409)

**확인 뒤 삭제**

```json
{
  "status": 200,
  "body": {
    "ok": true,
    "remaining": 0,
    "loggedOut": true
  }
}
```

> ✅ 통과 — 삭제되면 즉시 로그아웃된다 (T08-C46)

**패스키가 하나도 없는 계정으로 로그인 시도**

```json
{
  "status": 401,
  "body": {
    "error": "unknown_credential",
    "message": "서버에 등록되지 않은 패스키입니다."
  }
}
```
